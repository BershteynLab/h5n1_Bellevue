NYC Zip Code Risk Assessment - Component Maps

About: This dashboard provides separate visualizations for each risk component contributing to the overall H5N1 risk score.

Early Outbreak Risk: Components that indicate where the virus is most likely to enter the human population.

Long-term Burden Risk: Components that indicate areas at risk for sustained transmission and poor outcomes.

Modeled ZIP incidence: NYC compartment-model daily incidence apportioned to ZIPs using weights ∝ population × composite risk — illustrative only, not fitted spatial mixing. Opens as a peak-day snapshot; a full-window time slider is linked from that map (and documented in docs/epi_model/scenario_zip_incidence_map.md). Regenerate with python3 src/epi_model/scenario_incidence_folium.py from the repo root.
